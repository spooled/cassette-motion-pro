# v1.22.0 Position-Based Before/After History — Test Plan

## Build and upgrade

- Confirm GitHub Actions completes and produces both the portable zip and installer.
- Open an existing client/session created by an earlier version and confirm it loads normally.
- Save the older session once, close it, reopen it, and confirm its original Before/After data remains intact.

## Create position history

1. Open or create a client fit session and enter Before measurements and media.
2. From **Fit Day**, choose **Position History**.
3. Save `Baseline` using **Baseline (Before)**.
4. Change the session’s After measurements and save the session.
5. Reopen **Position History**, enter `Saddle +5 mm`, describe the adjustment, and save **Adjustment (After)**.
6. Save a third position as **Final (After)**.

Expected:

- All three positions appear in sequence with their saved time and stage.
- Selecting an adjustment shows its notes and measurement changes from Baseline.
- Only one position is marked FINAL.
- The position snapshot does not overwrite the existing Before/After fields or files.

## Edit and persistence

- Mark a different position final and confirm the earlier final marker is cleared.
- Delete a non-final test position and confirm the confirmation prompt appears.
- Close the workspace, reopen the same client/session, and confirm the remaining positions persist.
- Open **Session Timeline** and confirm each saved position appears chronologically.

## Report

- Preview or generate the client report.
- Confirm **Fit Position History** lists the positions in order with their stage and notes.
- Confirm the standard Before/After measurements and images still appear as configured.

## Laptop check

- Test at 1366×768 with the fit panel visible.
- Confirm Position History can be opened from Fit Day and Client History.
- Resize its window to the minimum size and confirm the position list, comparison, and action buttons remain reachable.
