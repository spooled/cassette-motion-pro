# Cassette Motion Pro v1.11.5 test plan

## Wheelbase-only saddle height

1. Open the reference bike image and select **Dual-wheel perspective**.
2. Enter the bike's measured wheelbase (1050 mm for the current reference bike).
3. For a 700c bike, leave **Wheel preset** at 700. Do not measure the outside tire diameter.
4. Complete the eight wheel points and four basic bike landmarks.
5. Confirm the results show **Saddle-height source: Wheelbase-only scale (tire size not required)**.
6. Compare the untouched saddle-height result with the 684 mm tape measurement.
7. Change the wheel preset while leaving all image points unchanged and confirm the saddle-height result does not change.

## Saddle-to-hood

1. Enable **Use tape value when camera view is angled**.
2. Enter 595 mm and confirm the saved saddle-to-hood value is exactly 595.0 mm and labeled **Tape verified**.

## Regression

1. Confirm calibration warnings still catch badly misplaced wheel points.
2. Confirm saddle setback, Before/After saving, capture, playback, drawing, zooming, panning, and landmark dragging remain available.
