# v1.25.0 Full Fit-Day Usability and Reliability Pass — Test Plan

## Build and upgrade

- Confirm GitHub Actions produces the portable ZIP and installer labeled 1.25.0.
- Open an existing client and session from v1.24.0 or earlier; confirm media, measurements, approvals, report selections, and position history still load.
- Confirm the v1.24.0 client report layout remains intact.

## Fit-Day Preflight

1. Open a client and select **Fit Day**.
2. Confirm **Fit-Day Preflight** is visible beside the primary workflow controls without opening More Options.
3. Run it before opening a session and confirm it clearly identifies the missing active session.
4. Open a session and run it again.
5. Confirm client-folder access, free storage, autosave, session serialization, Before/After folders, report folders, capture, and playback are checked.

## Autosave and recovery

1. Edit the session title or goals and confirm the header changes to **Unsaved changes**.
2. Wait about four seconds and confirm it changes to **Saved** with a time.
3. Temporarily make the session location unavailable or read-only, then edit a field.
4. Confirm the header says **Autosave failed — press Save** and the message explains the failure.
5. Restore access, press **Save**, and confirm the warning clears.
6. Force-close during an unsaved test session, reopen the same client, and confirm the recovery prompt restores the session and last workspace section.

## Safe session switching

1. Edit one session and immediately select another session.
2. Confirm the first session saves and the selected session opens with the correct header and folders.
3. Repeat while the session folder is unavailable.
4. Confirm switching is paused, the original session remains active, and no edits disappear.
5. With unsaved changes, select **New Session** and repeat both the successful-save and failed-save cases.

## Fit-day regression

- At 1366×768, complete Intake → Record → Track → Measure → Approve → Report.
- Confirm Ctrl+1 through Ctrl+5 open Fit Day, Client, Video, Measurements, and Report in that order.
- Press F6 and confirm it performs the same protected Next Step action as the on-screen button.
- Confirm the navigation bar never covers content and all primary actions remain reachable.
- Save Before/After videos and report images; confirm they enter the active session folders.
- Close normally and confirm no recovery prompt appears on the next launch.
- Preview the report and prepare a package and ZIP.

## Report workspace cleanup

1. Select **Report** and confirm the Client Report Center opens without a second Review/Builder navigation strip.
2. Open **Report Builder** and confirm only the report tabs appear beneath the main workflow bar.
3. Confirm Report Builder shows editable recommendations plus **Check Readiness**, **Preview Report**, and **Review + Deliver** without duplicate section or package buttons.
4. Open **Review & Deliver** and confirm the review controls fit on one row at 1366×768.
5. Confirm **Mark Complete**, **Create Package**, **Create ZIP**, **Portal Package**, and **Open Reports** are visible and work independently.
6. Click the main **Report** stage again and confirm it returns to the Client Report Center overview.
