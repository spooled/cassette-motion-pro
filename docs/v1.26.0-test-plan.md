# v1.26.0 Safer Sessions, Client-Safe Reports and Visual Polish — Test Plan

Run on a test client, not live client data.

## Build and upgrade

- Confirm GitHub Actions produces the portable ZIP and installer labeled 1.26.0.
- Open a client and sessions from v1.25.0 or earlier; confirm media, measurements, approvals, report selections, and position history still load.
- Confirm existing sessions keep their current folders (no new duplicate session folders appear).

## Stable session folders

1. Create a session and save a Before clip.
2. Change the session date and save.
3. Confirm **Before Videos** still opens the folder containing the clip.
4. Create another session, change its date before saving anything, and confirm its folders do not move afterwards.

## Client-safe package and ZIP

1. On the Handoff tab, enter text in the internal notes.
2. Approve the report and create the package, then the ZIP.
3. Open the ZIP: it must contain only the report, `Images/`, and `Client Handoff Notes.txt`.
4. Confirm there is no `Fitter Only` folder in the ZIP and the internal note text appears nowhere in it.
5. Confirm the package folder on disk has a `Fitter Only` folder holding the summary, internal handoff notes, metrics review, and evidence manifest.

## Save and recovery

1. Edit a session, then end the app from Task Manager.
2. Reopen the client and accept the recovery prompt.
3. Confirm the edit is present, the session appears in the list, and no second folder for it was created.
4. Make the recovery folder read-only, edit and save, and confirm the save still succeeds.
5. Open Fit Day on a client, add a follow-up from Client Manager, then edit and save in Fit Day; confirm the follow-up is still present.

## Visual polish

- Step through Fit Day, Client, Video, Measurements, and Report; confirm buttons are rounded and show hover, pressed, disabled, and focus states.
- Open Guided Capture, Report Approval, Studio Settings, Backup, and Session Media Library; confirm text is not clipped.
- Open a generated report on a phone-width window and when printed; confirm no content is cut off.
