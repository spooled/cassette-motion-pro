# v0.96.0 Integrated Report Center — Test Plan

## Open the report center

1. Open a client and fit session.
2. Click **Report** in the persistent fit-day header.
3. Confirm the Fit Panel opens directly to **Report Center** inside the main window.
4. Confirm the client, session, readiness, measurements, evidence, and approval summaries are correct.

## Header visibility

1. Click **Hide Fit Header** on the main toolbar.
2. Confirm the persistent fit-day header disappears and the video workspace gains the space.
3. Confirm the active client session and Fit Panel remain open.
4. Click **Show Fit Header** and confirm the same client, session, media, autosave, and next-action state returns.
5. Hide the header, change fit data, then show it again and confirm the displayed state is current.

## Edit recommendations

1. Enter or revise text in **Client recommendations — edit here**.
2. Click **Save Report Draft**.
3. Leave the Report Center, return to it, and confirm the recommendations remain.
4. Open the existing Fit Summary page and confirm the same recommendations appear there.

## Choose report images

1. Use **Choose Before**, **Choose After**, and **Choose Side-by-side**.
2. Confirm each chosen image is copied or retained inside the active client session as expected.
3. Confirm the saved-image count and filenames update in the evidence summary.
4. Test **Latest Side-by-side** and verify the newest saved side-by-side image is selected.
5. Test **Open Image Folder** and confirm it opens the active session’s Report Images folder.

## Preview and approval

1. Click **Preview / Save PDF**.
2. Confirm the generated report opens with the latest recommendations and selected images.
3. Use the report’s **Print / Save PDF** control and confirm the PDF can be saved.
4. Return to Report Center and click **Review + Approve Report**.
5. Confirm the approval summary changes to approved.
6. Edit recommendations or change an image and confirm approval becomes pending again.

## Delivery

1. After approval, test **Prepare Package** and confirm its folder opens.
2. Test **Prepare ZIP** and confirm the ZIP appears in the session Reports folder.
3. Test **Portal Package** and confirm the client-ready portal folder and ZIP are created.
4. Test **Open Reports** and confirm it opens the active session’s Reports folder.

## Regression checks

1. Confirm recording, playback, drawing tools, and Before/After/Dual media saves still work.
2. Confirm the persistent header’s **Do Next** action still works.
3. Test on the laptop and confirm the Report Center scrolls to every action.
4. Switch clients and confirm recommendations, images, approval, and delivery paths change to the new active session.
5. Confirm the GitHub Actions Windows build passes and produces the portable bundle and installer.
