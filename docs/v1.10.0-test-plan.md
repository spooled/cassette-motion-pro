# Cassette Motion Pro v1.10.0 test plan

## Bike Reference calibration

1. Open a client fit session and start Before Bike Measurements from a clear side-view image.
2. Confirm **Bike reference (recommended)** is selected.
3. Measure and enter the actual axle-center wheelbase and the unloaded outside tire diameter.
4. Click rear axle center, front axle center, top of tire, and bottom of the same tire.
5. Confirm the screen shows separate horizontal and vertical mm/pixel scales and an X/Y difference grade.
6. Confirm the axle line is automatically shown as the level reference.
7. Complete the landmarks and confirm horizontal metrics use wheelbase scale while vertical metrics use tire scale.
8. Deliberately move one tire point and confirm the X/Y disagreement increases and changes to Review when large.

## Known Reference / Board compatibility

1. Change Calibration to **Known reference / board**.
2. Confirm wheelbase and tire fields become unavailable.
3. Calibrate one known line and verify it with a second known line.
4. Confirm the existing guided landmark, save, and report workflow still works.

## Direction and repeatability

1. Repeat Bike Reference calibration with a bicycle facing the opposite direction.
2. Confirm the two axle centers still produce the correct level reference and positive wheelbase magnitude.
3. Repeat the four clicks twice and compare the saved measurements for consistency.
