# Cassette Motion Pro v1.11.8 test plan

## Saddle-tip-to-bar-center assistance

1. Complete bike calibration and select **Advanced landmarks (8 points)**.
2. Place the bottom bracket, saddle tip, and handlebar center carefully. If an edge is used, confirm the correct edge mode and bar diameter.
3. Record the camera-derived Handlebar X/Y values.
4. Measure the straight line from the saddle tip to the handlebar center with a tape.
5. Enable **Use tape saddle tip → bar center** and enter that distance.
6. Confirm Handlebar X/Y update and remain referenced to the bottom bracket.
7. Confirm the source reads **BB reference + tape saddle-tip-to-bar-center length + image direction**.
8. Disable the option and confirm the original image-derived coordinates return.

## Meaning and safety

1. Confirm the tape value changes the length of the saddle-to-bar vector while retaining its direction from the image.
2. Confirm the software does not claim that X and Y were independently tape-measured.
3. Confirm the option is disabled in Basic 4-point mode because that mode records the hood contact point rather than the bar center.

## Regression

1. Confirm tape-calibrated saddle height and the saddle-to-hood tape override still work.
2. Confirm Before/After saving, capture, playback, drawing, zooming, panning, and landmark dragging are unchanged.
