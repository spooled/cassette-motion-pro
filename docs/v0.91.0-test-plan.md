# v0.91.0 integrated client selector — fit-day checks

Use a disposable client first. This build integrates client selection into the Video Studio toolbar and keeps one fit workspace available while you capture or analyze; it does not yet embed the full report workspace in the video canvas.

1. Open the app. In the Video Studio toolbar, choose **Choose client + session**. Search by a client name or bike, then select a client. Confirm the correct fit workspace opens and the toolbar shows that client.
2. Open or create a fit session. Confirm the toolbar shows the active session name. Use **Fit Workspace** to return to the same session, not a second copy.
3. From the workspace, start dual live capture. Confirm the workspace gets out of the way, the two Kinovea capture screens appear, and camera folders still point to the active client's Before and After destinations.
4. Click **Fit Workspace** in the toolbar, then open Before/After analysis. Confirm two playback screens open with the expected videos and the drawing/measurement tools still work.
5. Return to the workspace, save a note and an image, then close and reopen the session. Confirm the note, image path, and client context persist.
6. Switch to a different test client from the toolbar. Confirm the first workspace saves and closes, and the new client's session opens without mixing folders. If a save fails, the old workspace must stay open and the app must not switch clients.
7. Close the app with an active test session and reopen it. Confirm the latest complete session data is present. Check the GitHub Actions Windows build before using this version for a real fit.

If the selector is cramped at your normal screen resolution or a capture button leaves the workspace covering Video Studio, record a screenshot and the button you used.
