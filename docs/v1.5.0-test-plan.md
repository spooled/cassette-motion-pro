# Cassette Motion Pro v1.5.0 test plan

This milestone puts report images, recommendations, branding, preview, approval, and delivery into one Client Report Center. The fitter still controls every recommendation, image, approval, and delivery action.

## 1. Client Report Center

1. Open a client and fit session, then select **Report**.
2. Confirm **Client Report Center** opens first and the whole page scrolls on a laptop-sized screen.
3. Confirm the page order is recommendations, report images, branding, review status, approval, preview, and delivery.

## 2. Images and recommendations

1. Confirm the saved Before, After, and side-by-side images appear as visible thumbnails.
2. Click **Use Latest** for each image type and confirm it picks the newest matching image from the active client session.
3. Click **Choose…**, select another saved client image, and confirm its thumbnail and filename update.
4. Click **Build Editable Draft**, review or change the wording, and save the report draft.
5. Close and reopen the session and confirm the edited recommendation text and selected images return.

## 3. Branding and PDF preview

1. Switch among Full Cassette logo, CM badge, and No logo; confirm the chosen style appears in the preview.
2. Open **Studio Details + Logo**, update studio or fitter details, and confirm the branding summary updates.
3. Click **Preview / Print PDF** and confirm the client preview opens with a review reminder that does not appear in the printed PDF.
4. Review the client name, bike, recommendations, measurements, Before/After images, studio details, and page breaks.
5. Use **Print / Save PDF** and confirm the saved PDF is readable and client-ready.

## 4. Approval and delivery

1. Confirm the delivery status says preview and approval are still needed before approval.
2. Approve the report and confirm the status changes to **Ready to deliver**.
3. Test **Prepare Package**, **Create ZIP**, **Portal Package**, and **Open Reports**.
4. Confirm every created item stays inside the active client's session folders and no other client's media is included.

## 5. Existing tools

1. Confirm Fit Summary and detailed report-builder pages still open from the Client Report Center.
2. Confirm measurements, favorite frames, capture, playback, drawing, and native Kinovea tools remain unchanged.

## Pass condition

The milestone passes when the fitter can prepare a client-ready report from one scrolling page, visually verify the selected images, edit recommendation wording, confirm branding, preview and save the PDF, approve it, and create the chosen delivery package without leaving the active client session.
