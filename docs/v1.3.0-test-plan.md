# Cassette Motion Pro v1.3.0 test plan

This milestone reorganizes the Video workspace around dual capture, Before/After playback, visible readiness, and faster favorite-frame selection. Kinovea remains the capture, playback, drawing, and measurement surface.

## 1. Video Fit Desk

1. Open an existing client and fit session, then select **Video**.
2. Confirm the Video Fit Desk appears at the top of the page.
3. Confirm the Before, After, and Favorites cards show **Needed** when their files are missing.
4. Select or save media and confirm the cards change to **Ready** with the selected file information.
5. Confirm the next-step message progresses from Before recording to After recording, favorite selection, comparison approval, and report readiness.

## 2. Dual capture and playback

1. Click **Record Before** and confirm two capture screens open into the active session's Before destination.
2. Record and save a Before take, then use **Record After** and confirm both capture screens use the After destination.
3. Return to the same session and click **Play Latest Before + After**.
4. Confirm the newest Before and After clips are selected and open in two playback screens.
5. Confirm both file paths and readiness cards update correctly.

## 3. Faster favorite frames

1. Save several images from Before playback using Kinovea's Save Image control.
2. Save several images from After playback.
3. Click **Choose Before Frame** and confirm the Before review opens directly without asking which side.
4. Click **Choose After Frame** and confirm the After review opens directly.
5. Confirm both chosen frames appear as ready in the Favorites card.
6. Click **Compare Favorites**, approve the pair, and confirm the card shows approval.

## 4. Existing video tools

1. Confirm Browse, Record Live, Use Latest, and Analyze still work on each individual media row.
2. Confirm camera profiles remain editable and can open Before or After dual capture.
3. Confirm camera synchronization and Saved Media remain available.
4. Confirm Before and After folder shortcuts still open the active session folders.
5. Use drawing and measurement tools during playback and save Before, After, and Dual evidence.

## 5. Automatic measurement images

1. With a client fit session open, save one paused frame as **Before** and another as **After** using Kinovea's Save Image control.
2. Open **Measurements** and click **Use Before Image**. Confirm the newest image from that session's Before folder is selected without a file browser.
3. Click **Use After Image** and confirm the newest image from the After folder is selected without a file browser.
4. Start the guided Before and After rider measurements and confirm they open the corresponding saved image automatically.
5. Start the Before/After tracking comparison and confirm it uses both saved session images.
6. Repeat with an older session that stores Before/After images directly in the Report Images folder and confirm those images are still found.
7. Try a side with no saved image and confirm the message explains how to save a paused frame into the missing slot.

## Pass condition

The milestone passes when the Video Fit Desk accurately reflects saved media, dual capture and latest-pair playback open correctly, favorite frames can be selected directly by side, measurement tools automatically load saved session images, and all existing capture, playback, synchronization, folder, and evidence-saving behavior remains available.
