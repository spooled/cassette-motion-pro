# Cassette Motion Pro v1.2.0 test plan

This milestone simplifies navigation inside the unified Fit Panel. It does not replace Kinovea's capture, playback, drawing, measurement, or export tools.

## 1. Primary fit stages

1. Open a client and create or open a fit session.
2. Confirm the old full tab row is no longer visible.
3. Open **Fit Day**, **Client**, **Video**, **Measurements**, and **Report** from the stage strip.
4. Confirm the active stage is highlighted and each stage opens the expected workspace.
5. Resize the Fit Panel narrower and confirm the stage strip can scroll without covering the workspace.

## 2. Contextual navigation

1. Open **Client** and confirm only **Setup**, **Files**, and **History** appear below the stage strip.
2. Open each client section and confirm Client stays highlighted.
3. Open **Report** and confirm only **Review** and **Builder** appear.
4. Open each report section and confirm Report stays highlighted.
5. Return to Fit Day, Video, or Measurements and confirm the contextual row disappears to return that space to the current work.

## 3. Fit-day path

1. Enter or update client/session details under Client > Setup.
2. Open Video and record or analyze Before and After media.
3. Use a Kinovea drawing or measurement tool and save evidence to the active session.
4. Open Measurements and review or approve measurement evidence.
5. Open Report > Review, then Report > Builder, and preview the PDF.
6. Use the bottom Save and Next Step actions at each stage and confirm they still lead to the expected next action.

## 4. Regression and recovery

1. Hide and show the persistent Fit Header.
2. Hide and show the Fit Panel while video remains open.
3. Switch between two existing sessions for the same client.
4. Close and reopen the active session and confirm its last saved data returns.
5. Confirm Before, After, and Dual image/video save prompts still use the active client session.

## Pass condition

The milestone passes when the five-stage strip replaces the duplicate navigation, contextual choices appear only under Client and Report, the full client-to-report workflow remains reachable, and the existing Kinovea tools and save routing continue to work.
