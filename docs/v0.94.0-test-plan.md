# v0.94.0 Persistent Fit-Day Header — Test Plan

## Main fit-day path

1. Open Cassette Motion Pro and choose a client.
2. Open or create a fit session.
3. Confirm the top fit-day header shows the correct client and session.
4. Click **Video ›** or **Hide Fit Panel**.
5. Confirm the header remains visible above the Kinovea video workspace.

## Status checks

1. With no saved videos, confirm Before and After show as missing.
2. Save or assign a Before video and confirm Before changes to a check mark.
3. Save or assign an After video and confirm After changes to a check mark.
4. Edit a session field and confirm the autosave message updates after saving.
5. Complete the current recommended step and confirm the Next message advances.

## Do Next action

1. Hide the Fit Panel.
2. Click **Do Next** in the persistent header.
3. Confirm the Fit Panel opens and takes you to the recommended fit stage.
4. Repeat after completing intake, Before/After media, measurements, and report preparation.

## Layout and regression checks

1. Test at laptop resolution and confirm all header sections remain readable or shorten with an ellipsis.
2. Confirm the Fit Panel can still be shown and hidden normally.
3. Confirm dual capture, dual playback, drawing tools, and video saving still work.
4. Switch clients and confirm the header immediately changes to the new client/session.
5. Close the fit workspace and confirm the header is removed.
6. Confirm the GitHub Actions Windows build passes and produces the portable bundle and installer.
