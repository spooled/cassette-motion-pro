# Cassette Motion Pro v1.4.0 test plan

This milestone puts tracking, assisted measurements, corrections, confidence, and fitter approval into one Measurement Review Center. The checks remain guidance; the fitter controls every correction and approval.

## 1. Measurement Review Center

1. Open a client and fit session, then select **Measurements**.
2. Confirm **Measurement Review** opens first instead of requiring another tab selection.
3. Confirm the four cards are visible: Tracking, Assisted measurements, Corrections + consistency, and Confidence + approval.
4. Resize the fit panel on a laptop-sized display and confirm the page scrolls and every action remains reachable.

## 2. Tracking and assisted measurements

1. Save a Before and After image in the active fit session.
2. Use **Measure Before Rider** and **Measure After Rider** and confirm each opens its session image without a file browser.
3. Run Before and After short-clip tracking and confirm each card status updates after returning to the center.
4. Open **Compare Before + After** and confirm approved rider values return to the combined table.
5. Start **Guided Bike Measurements**, save values, and confirm the combined table updates.

## 3. Corrections and confidence

1. Use **Correct Before Tracking** or **Correct After Tracking** and confirm corrected joint points remain fitter-controlled.
2. Save a Repeatability Lab check and confirm the Corrections card shows the saved check count.
3. Run Camera + Tracking Quality and Calibration Test and confirm their status appears on the Confidence card.
4. Run **Review + Approve**, confirm both fitter acknowledgements, and verify the card changes to Approved.
5. Change a measurement after approval and perform a fresh review before final report approval.

## 4. Detailed editors and existing tools

1. Confirm Edit Bike Metrics, Edit Body Angles, and Open Report Builder still open their detailed pages.
2. Confirm Run Quality Check still reports missing, unusual, or large-change values without blocking the fitter.
3. Confirm Kinovea playback, drawing, calibration, and native measurement tools remain unchanged.
4. Save, close, and reopen the fit session; confirm measurements, repeatability checks, tracking summaries, confidence notes, and approval are restored.

## Pass condition

The milestone passes when the Measurement Review Center is the default Measurements page, all four review stages are usable without leaving the client workspace, saved Before/After images are found automatically, status updates reflect saved session work, and detailed editors and Kinovea tools remain available.
