# v0.92.0 unified fit-day layout — test plan

Use a disposable client first. This build moves the existing fit workspace into the main application window; it does not replace Kinovea's native capture, playback, drawing, or export controls.

1. Open the app and choose a client from the toolbar. Confirm the fit workspace appears as a right-side panel inside the same main window—not as a separate window—and the active client/session appears in its header.
2. Use **Hide Fit Panel**, **Show Fit Panel**, and the panel's **Video ›** button. Confirm the central video area expands when the panel is hidden and the same client/session returns when shown.
3. Create or open a session, enter a short note, hide and show the panel, and confirm the note remains. Save, close, and reopen the session to confirm it persisted.
4. Start dual live capture from the fit panel. Confirm the panel collapses, two Kinovea capture screens remain usable, and the Before/After client destinations stay selected.
5. Show the fit panel again and open Before/After analysis. Confirm the panel collapses, two playback screens open, and all Kinovea playback and drawing tools remain visible and usable.
6. Save Before, After, and Dual test evidence. Confirm every file routes to the active session and appears in its media/evidence views.
7. Switch to a second disposable client from the toolbar. Confirm the original session saves and the new client replaces the panel without mixing media folders. If a save error is shown, the original panel must remain active.
8. Resize the main window at the screen size used during fittings. Confirm the panel content can be reached and the menu, toolbar, status bar, video controls, and drawing tools are not covered.
9. Close the app while the panel is open, reopen it, and verify the last completed save. Confirm the GitHub Actions Windows build passes before using v0.92.0 for a real fit.

Capture a screenshot if the panel covers Kinovea controls or if any workspace button is unreachable; include the screen resolution and Windows display scaling.
