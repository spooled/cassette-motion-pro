# v1.24.0 Professional Client Report Redesign — Test Plan

## Build and upgrade

- Confirm GitHub Actions produces the portable ZIP and installer labeled 1.24.0.
- Open a client session created in an earlier version and confirm its report fields and selected images still load.
- Confirm existing report packages remain untouched when a new report is generated.

## Report Center

1. Open a client fit session and select **Report**.
2. Confirm the page is titled **Professional Client Report**.
3. Confirm the fit-plan editor, client-evidence image picker, branding controls, and output actions remain reachable on a 1366×768 laptop.
4. Choose Before, After, and side-by-side images and confirm each preview matches the selected file.
5. Select **Preview Client Report**.

## Client-facing report

1. Confirm the report opens with the client, bike, session date, and main fit goal.
2. Confirm **Your Fit Plan** presents key findings, changes made, recommendations, and follow-up using clear cards.
3. Confirm **Final Position Snapshot** appears near the beginning when final bike values are available.
4. Confirm Before/After tables use **Baseline**, **Final**, and **Difference** headings.
5. Confirm selected comparison images are large, correctly labeled, and not cropped.
6. Confirm missing optional information displays gracefully without blank broken sections.

## Print and PDF

1. Choose **Print / Save PDF** from the preview.
2. Confirm the preview-only **Report Readiness** section is not included in print or PDF output.
3. Confirm cards, tables, headings, and images do not split awkwardly across pages.
4. Confirm the studio logo, fitter details, contact information, confidentiality notice, and version 1.24.0 footer are present.
5. Generate a package and ZIP; open the packaged HTML and confirm its images work without access to the original session folder.
