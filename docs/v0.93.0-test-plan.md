# v0.93.0 unified layout polish — test plan

Use a disposable client and the laptop/display scaling used during real fittings.

1. Open a client and session. Confirm the embedded header is shorter, the session list is narrower, and the selected workspace stage has more room than v0.92.0.
2. Open **Fit Day**. Confirm Next Step, Resume Last Stage, and Workflow Check remain visible. Open **More Options + Folders** and confirm Diagnostics, Practice Mode, Getting Started, Session Timeline, and folder tools are reachable by scrolling.
3. Visit Session Setup, Client Files, Client History, Record/Analyze, Measurements, and Report. Confirm each page scrolls vertically when its content is taller than the panel and button rows can be scrolled without hiding actions permanently.
4. On non-report stages, confirm the bottom bar shows Save and Next Step without the report-only controls. On Report, confirm it shows Save Draft, Review, Preview, and the Before-measurements option.
5. Use Next Step across Intake, Record, Track, Measure, and Approve. Confirm it opens the expected stage and never skips the active-session requirement.
6. Start dual capture and Before/After analysis. Confirm the panel collapses and all Kinovea camera, playback, drawing, and measurement controls remain usable.
7. Save notes, measurements, images, and videos; reopen the session and confirm nothing was lost or routed to another client.
8. Resize the application and test Windows display scaling used in the studio. Confirm buttons remain large enough to press and no required action becomes unreachable.
9. Confirm the GitHub Actions Windows build passes before using v0.93.0 for a real fit.
