# Cassette Motion Pro v1.6.0 real fit-day test plan

This milestone is a field-testing pass. Use it during a complete fitting on the actual Windows laptop, with the actual cameras and trainer. Do not mark a stage Pass until it has been performed with the active client session.

## Before the rider arrives

1. Open the intended client and create a new fit session.
2. Open **Fit Day → More Options + Folders**.
3. Run **Practice Mode** and confirm both camera views and playback.
4. Run **Fit-Day Diagnostics** and resolve unexpected failures.
5. Open **Run Field Test** after each major stage, record the result, and save it. Reopening it must restore the earlier stage results and observations.

## Full fitting path

1. Complete client goals and session details.
2. Record dual-camera Before video and confirm both files use the active client's Before folders.
3. Open the Before clips in playback, save favorite frames, and confirm report images save without browsing.
4. Record and review After video after the fit changes.
5. Complete tracking, measurements, corrections, and fitter approval.
6. Record the fit changes and edit the client recommendations.
7. Confirm the Client Report Center shows the intended Before, After, and side-by-side images.
8. Preview the PDF and verify client details, branding, images, measurements, wording, and page breaks.
9. Approve and create the intended delivery package.
10. Close and reopen the client session; confirm the information, media paths, approvals, and timeline return.

## Record friction correctly

For every stage in **Run Field Test**:

- Choose **Mark Pass** only when the real action worked.
- Choose **Log Friction** when an action is slow, confusing, incorrect, or unreliable.
- In the observation box, record what you clicked, what you expected, and what happened.
- Leave unfinished stages as **Not Tested**.
- Click **Save Field Test**. The record must appear in the active session's Reports folder and the Session Timeline.

## Reliability checks

1. Confirm autosave changes from Unsaved to Saved after editing session data.
2. Confirm selected Before/After media still exists after reopening.
3. Confirm no media or report files were written into another client's folders.
4. Confirm every important action remains reachable on the studio laptop without hidden buttons.
5. Confirm Kinovea capture, playback, drawing, and native measurement tools behave normally.

## Pass condition

v1.6.0 passes field testing when one complete fitting reaches client delivery, all nine field-test stages have a result, session data survives reopening, files remain in the correct client folders, and every recorded friction item is either understood or scheduled for correction.
